Employee Analytics Dashboard using MySQL + Power BI
📌 Project Overview

This project demonstrates an end-to-end Business Intelligence workflow by integrating a MySQL database with Power BI to create interactive HR Analytics dashboards.

The objective of this project was to transform raw employee and training data into meaningful business insights through SQL querying, data modeling, DAX calculations, and executive-level dashboard design.

This is my first project involving direct MySQL database connectivity with Power BI, helping me gain practical experience in:
*Database connectivity
*SQL-based data extraction
*Data transformation
*Data visualization
*KPI reporting
*HR analytics
